## 🏗️ Engenharia de Software

Além do desenvolvimento de aplicações, venho aprofundando meus conhecimentos em princípios, práticas e fundamentos de Engenharia de Software, buscando construir soluções mais organizadas, sustentáveis e de fácil manutenção.

### 🧠 Arquitetura e Design de Software

- Arquitetura de Software
- Clean Architecture
- Arquitetura em Camadas
- Princípios SOLID
- Clean Code
- Design Patterns
- Separação de Responsabilidades
- Baixo Acoplamento e Alta Coesão

### ⚙️ Qualidade e Desenvolvimento

- Boas práticas de desenvolvimento
- Refatoração e manutenção de código
- Testes automatizados
- Tratamento de erros e validações
- Design e integração de APIs REST
- Versionamento com Git
- Code Review

### ☁️ Tópicos em evolução

- Fundamentos de Cloud Computing
- Docker e conteinerização
- CI/CD e automação de processos
- Observabilidade e monitoramento
- OpenTelemetry
- Inteligência Artificial aplicada ao desenvolvimento de software

> Meu objetivo é evoluir além da implementação de funcionalidades, compreendendo decisões arquiteturais, qualidade de código e o ciclo de vida das soluções de software.
