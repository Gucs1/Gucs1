## 🏗️ Engenharia de Software

Tenho direcionado minha evolução profissional ao estudo e à aplicação de princípios e práticas de Engenharia de Software.

Meu objetivo é desenvolver soluções que não apenas funcionem, mas que também sejam **organizadas, testáveis, escaláveis e sustentáveis ao longo do tempo**.

### 🧠 Arquitetura e Design de Software

- Arquitetura de Software
- Clean Architecture
- Arquitetura em Camadas
- Princípios SOLID
- Clean Code
- Design Patterns
- Separação de Responsabilidades
- Baixo Acoplamento e Alta Coesão

### ⚙️ Qualidade e Boas Práticas

- Refatoração e manutenção de código
- Testes automatizados
- Tratamento de erros e validações
- Design e integração de APIs REST
- Versionamento com Git
- Code Review
- Organização e evolução de sistemas legados

### ☁️ Conhecimentos em evolução

- Fundamentos de Cloud Computing
- Docker e conteinerização
- CI/CD e automação de processos
- Observabilidade e monitoramento
- OpenTelemetry
- Inteligência Artificial aplicada ao desenvolvimento
